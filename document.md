# AirBuddy — Project Documentation

## 1. Overview

AirBuddy is a GenAI-powered web assistant that helps families and communities navigate severe winter smog and urban air pollution. It gives personalised, plain-language advice on indoor air quality, low-emission daily routines, and sustainable alternatives, based on the user's location, household situation, and current AQI.

The advice is generated by a free large language model accessed through OpenRouter, and the application is built with Python (Flask) on the backend and plain HTML/CSS/JavaScript on the frontend.

## 2. Features

| Feature | Description |
|---|---|
| Region → City selection | Two cascading dropdowns. Choosing a region loads only that region's cities from the backend. |
| Region reset on refresh | The region dropdown always returns to "-- Select Region --" when the page is reloaded, instead of remembering the previous choice. |
| Personalised advice | Sends AQI, region, city, household situation, and a free-text question to the LLM. |
| Popup result | Advice appears in a modal popup with the title "AirBuddy says" and a black ✕ close button. |
| Close options | The popup can be closed with the ✕, by clicking the dark background, or by pressing Esc. |
| Free quota display | After each request, the popup shows how many free OpenRouter requests have been used, the limit, and the remaining amount. |
| Error handling | Rate-limit (429) or network failures are shown in dark red inside the same popup, with a friendly fallback message. |
| Theme | Sky blue and white background, black text throughout. |

## 5. Configuration

Create a `.env` file in the project root:

```ini
OPENROUTER_API_KEY=sk-or-v1-your-actual-key-here
```

- Do not put quotes around the key.
- Do not add spaces around the `=`.
- The `.env` file must never be committed to version control.

The model is configured in `app.py`:

```python
MODEL = "openrouter/free"
```

`openrouter/free` is OpenRouter's free-model router. Instead of pinning a single free model, it automatically selects an available free model for each request. This avoids the problem of one specific model being temporarily unavailable or rate-limited, and it is the recommended setting when you want to stay entirely on the free tier. Any other `:free` model can still be substituted (for example `meta-llama/llama-3.3-70b-instruct:free`) without changing any other file.

## 6. Installation and Running

```bash

# 2. Install dependencies

```

Then open `http://127.0.0.1:5000` in a browser.

To stop the server, press `Ctrl + C` in the terminal.

## 7. How to Use

1. Enter the **Current AQI** (e.g. 150).
2. Choose a **Region** from the dropdown (USA, India, China, Japan, Europe, Africa).
3. Choose a **City** — the list is loaded automatically for the selected region.
4. Describe the **Household situation** (e.g. "Family with a child, elderly with asthma").
5. Type a **Question** (e.g. "How should we protect ourselves today?").
6. Click **Get Advice**.
7. The popup opens showing "Please wait…", then updates with the advice, followed by the free request quota.
8. Close the popup with the **✕**, by clicking the dark background, or by pressing **Esc**.

Refreshing the page resets the region dropdown to "-- Select Region --" and disables the city dropdown again.

## 8. Backend Reference (`app.py`)

### Routes

| Route | Method | Purpose |
|---|---|---|
| `/` | GET | Renders the form. Passes the region list to the template. |
| `/cities/<region>` | GET | Returns a JSON array of city names for the given region. |
| `/advice` | POST | Accepts the form data and returns the LLM-generated advice as JSON. |
| `/quota` | GET | Returns the OpenRouter free-model daily request usage as JSON. |

### `CITY_DATA` dictionary

All regions and cities are defined in one place in `app.py`:

```python
CITY_DATA = {
    "USA": ["Los Angeles", "Visalia", ...],
    "India": ["Kolkata", "Delhi", ...],
    "China": ["Beijing", "Chengdu", ...],
    "Japan": ["Tokyo", "Yokohama", ...],
    "Europe": ["Athens", "Bucharest", ...],
    "Africa": ["Dakar", "Johannesburg", ...],
}
```

To add a city, append its name to the relevant list. To add a region, add a new key with a list of cities. No other file needs to change.

### `/advice` request and response

Request body (JSON):

```json
{
  "aqi": "150",
  "region": "India",
  "city": "Delhi",
  "household": "Family with a child",
  "question": "How should we protect ourselves today?"
}
```

Success response:

```json
{ "ok": true, "advice": "..." }
```

Failure response (HTTP 500):

```json
{ "ok": false, "advice": "Sorry, AirBuddy cannot reach the air assistant right now. Please try again later.", "error": "..." }
```

### `/quota` response

```json
{
  "ok": true,
  "free_model_daily_requests": { "used": 5, "limit": 50, "remaining": 45 }
}
```

If OpenRouter cannot be reached, it returns `{ "ok": false, "error": "..." }` with HTTP 500.

### System prompt

The LLM is instructed to act as AirBuddy, give simple, warm, actionable advice for families, reply in concise natural English, and **never invent AQI numbers** — it only explains and advises.

## 10. Free Tier Limits (OpenRouter)

- `openrouter/free` is a free-model router and follows the same free-tier limits as individual free models.
- Free models are limited to **20 requests per minute** and **50 requests per day** for accounts with less than $10 in cumulative top-ups.
- After a one-time top-up of at least $10, the daily limit rises to **1,000 requests**; the per-minute limit stays at 20.
- The `/quota` route displays the real-time daily usage returned by OpenRouter, so the numbers shown in the popup are authoritative rather than hardcoded.

## 11. Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| "Sorry, AirBuddy cannot reach the air assistant right now." with `429` | Free-tier rate limit hit (per-minute or per-day). | Wait a minute or until the daily reset, or top up $10 once. |
| `401` error | Invalid or missing API key. | Check `.env` and restart the server. |
| "Network error" in the popup | Flask server not running. | Run `python app.py` and keep the terminal open. |
| "Quota information unavailable." | `/quota` call failed. | Check internet connection and API key; the advice itself still works. |
| Region dropdown remembers the old value | Browser form restoration. | Already fixed by the `pageshow` listener; make sure `index.html` is the latest version. |
| City dropdown stays on "Loading…" | `/cities/<region>` failed. | Check that the region key exists in `CITY_DATA` and the server is running. |
| Advice is vague or repetitive | `openrouter/free` routed to a weaker free model. | Retry, or pin a specific model such as `meta-llama/llama-3.3-70b-instruct:free`. |

## 12. Extending the Project

- **Add cities or regions:** edit `CITY_DATA` in `app.py`.
- **Change the model:** edit `MODEL` in `app.py`. Keep `openrouter/free` for automatic routing, or pin a specific `:free` model.
- **Automate AQI lookup:** add a route that calls a free air-quality API (e.g. Open-Meteo) and pre-fill the AQI field.
- **Persist user profiles:** store household details in a database so returning users do not re-enter them.
- **Add impact feedback:** calculate and show the estimated emission reduction for suggested low-emission choices.

## 13. Security Notes

- The API key is read only on the server via `python-dotenv` and is never sent to the browser.
- The `.env` file should be excluded from version control (add it to `.gitignore`).
- The app is intended for local or small-scale use; for public deployment, add authentication, input validation, and HTTPS.
